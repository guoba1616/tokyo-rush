# 本批素材接入

直接刷新游戏页面，或用浏览器重新打开项目根目录 index.html。素材保存在本地，world-pack.js、assets.js、character-pack.js 支持离线加载。

本批 31 个世界模型：

- 武器 4：手枪、冲锋枪、霰弹枪、突击步枪；已连接武器选择和人物持枪挂点。RPG 继续使用原来的备用外观。
- 公交车 1：独立的四轮、前轮转向、加速、刹车灯及损毁。
- 直升机 2：可驾驶直升机和警用追捕直升机；独立主旋翼、尾桨。
- 建筑 11：商业楼 3、高楼 3、住宅 3、工业建筑 2；沿用城市地块与碰撞尺寸。吉隆坡地标保留现有模型。
- 自然 5：两种树、棕榈、灌木、岩石；树木和棕榈沿用原位置与碰撞。
- 街道/家具 8：货柜、垃圾箱、路障、锥桶、停车标志、咖啡桌、椅子、盆栽。

车辆同时接入此前已下载的 race、race-future、truck、delivery-flat，并调整紧凑型车的车型映射；新平板货车会进入交通车流，出生点附近增加一辆可驾驶公交车。

静态建筑、植物、集装箱和街道装饰使用 InstancedMesh 批量绘制；贴图调色板烘焙到顶点颜色，避免文件名冲突和离线贴图路径问题。人物持枪挂点根据各骨骼的瞄准姿态校准。

验证：

- tools/test-world.cjs：31 个 GLB 的加载、尺寸/地面归一化、武器切换与方向、四轮位置、主/尾旋翼。
- tools/test-characters.cjs：8 个角色的独立骨骼、走路/奔跑/待机切换和模型尺寸。
- tools/import-smoke.html：实际游戏加载、6 类车辆加速/车轮/损毁、武器切换、主角冲刺、直升机起飞及建筑碰撞。
- tools/pack-world.js：从 assets/world/*.glb 重新生成离线素材包。

完整署名与修改记录见 LICENSES.md，游戏主菜单亦有“素材署名与许可”链接。
